## 학습 도구

| 도구 | 내용 |
|---|---|
| **섹션 퀴즈** | 섹션마다 본문 아래에 붙습니다. 문제 은행 **715문항** |
| **모의 문제지** | 최근 7회분 기출의 단원별 출제 비율대로 뽑습니다. 타이머·자동 채점 |
| **오답노트** | 틀린 문제가 자동으로 모입니다. 한번 틀림 · 틀렸다 맞음 · 여러번 틀림 · ★ 저장 |
| **암기 카드** | 챕터 부록의 핵심 암기 요약 **317장**. 밀어서 저장하고 저장함을 비워 나갑니다 |
| **약어 사전** | 본문에서 뽑은 영문 약어 **133개**. 그 약어가 나오는 섹션으로 바로 이동 |

문제 은행이 유일한 원본입니다. 섹션 퀴즈는 그것을 섹션으로 거른 것이고,
모의 문제지는 같은 은행을 전 범위로 씁니다.

## 그 밖의 기능

- 목차에서 바로 이동 · 읽기 진행바 · 맨 위로 / 맨 아래로
- 본문 전체 검색 (🔍 버튼 또는 `/` 키)
- 섹션마다 학습 완료 체크 → 홈에서 전체 진도율 확인
- 다크 모드
- 다이어그램 확대 보기
- 모바일 레이아웃 (주소를 홈 화면에 추가하면 앱처럼 사용 가능)
- 인쇄 시 본문만 깔끔하게 출력

## 기록되는 데이터

진도·오답·저장한 문제·암기 카드는 **사용 중인 브라우저에만** 저장되며
어디로도 전송되지 않습니다. 따라서 PC와 모바일의 기록은 서로 공유되지 않습니다.

홈 화면 아래쪽에 버튼이 둘 있습니다.

- **진도만 초기화** — 섹션 학습 완료 표시만 지웁니다
- **전체 초기화** — 진도 · 오답노트 · ★ 저장한 문제 · 저장한 암기 카드를 모두 지웁니다
