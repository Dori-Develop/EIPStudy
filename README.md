## 기능

- 목차에서 바로 이동 · 스크롤에 따라 현재 위치 표시
- 본문 전체 검색 (🔍 버튼 또는 `/` 키)
- 섹션마다 학습 완료 체크 → 홈에서 전체 진도율 확인
- 다크 모드
- 다이어그램 확대 보기
- 모바일 레이아웃 (주소를 홈 화면에 추가하면 앱처럼 사용 가능)
- 인쇄 시 본문만 깔끔하게 출력

## 기록되는 데이터

진도 체크는 **사용 중인 브라우저에만** 저장되며 어디로도 전송되지 않습니다.
따라서 PC와 모바일의 기록은 서로 공유되지 않습니다.
홈 화면 아래쪽 **진도 초기화** 버튼으로 언제든 지울 수 있습니다.
